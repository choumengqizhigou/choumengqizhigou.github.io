程序一直运行固然是好事，可是咱们用完之后，也不希望它一直这么运行下去。

**就让我们来终结这个循环吧！**

跳出循环的方式大致可以分为两种，一种是 **跳出当前循环** ，一种是 **跳出整个循环** 。

然后跳出整个循环呢也可以分为两种方式，一种是自己 **主动跳出循环** ，还有一种就是 **不满足循环的执行条件来跳出循环** 。

下面我们分别来演示下两种方式！


## 跳出当前循环

这里我们把收集运算符号的地方稍微改造一下。

原先的代码逻辑是，用户即使没有输入 `+ - * /` 四个运算符中的一个，我们处理的方式是给了 `"运算符输入有误，没有匹配到对应的计算方式"` 。

就是下面这句代码：

![运算符输入错误时输出信息的代码截图](images/67b47532-a6d8-4b51-9773-931024f0c3cc.png)

做完这个信息输出之后，代码依然会继续往下执行，同时还要输出 `$"第{calcNumb}次计算已经完成"` 。

实际运行起来就是：

![运算符输入错误时输出信息的运行截图](images/44748a48-c558-4b6e-bf49-446edb076c25.png)

这里我输入的运算符是 `啦啦啦` ，最终还是会输出 `"第1次计算已经完成"` 这样的信息。

目前咱们的处理逻辑就希望调整为：

**如果本次计算因为输入了一个非法的字符，导致计算无法完成，就应该即时终止这次计算，并直接进入到下一次计算。**

就不要再去输出什么 `"第x次计算已经完成"` 计算这样的消息了！

处理的方式其实很简单，加上 `continue;` 这样一句代码就行了。

就像这样：

``` Csharp

MyConsole.WriteLine("运算符输入有误，没有匹配到对应的计算方式");

// 跳出本次循环
continue;

```

只要用户输入了一个非法的运算符，进入了运算符判断的 `else` 范围，我们输出警告信息 `"运算符输入有误，没有匹配到对应的计算方式"` 之后，执行 `continue;` 直接跳出本次计算过程，进入下一次计算过程就行了。

也就是说，跳出本次循环，进入到下一次循环，重新收集数字和运算符，开始新的计算过程即可。

重新演示下效果就是：

![continue代码演示效果截图](images/90d3a7cb-c22e-4ba1-b932-d366e4616f3c.png)

同样是输入运算符 `啦啦啦` ，这次并没有去继续执行这个计算过程的后续代码了，而是跳出当前循环，直接开始从头执行下一次的计算过程代码。

> 我知道你在想什么，毕竟前面辛辛苦苦收集了两个数字，计算过程都快走完了，就因为这样一个运算符收集失败，就让我重新开始，这也很不合理呀！
> 依然要佩服你的远见，其实我们可以利用 `for循环` 来实现一个更好一点的运算符收集。当用户输入一个非法的运算符，其实可以让用户重新输入运算符，直到用户输入正确的运算符为止，而不是重新开始整个过程。另外就是前面收集数字也是有一样的问题，目前的做法是用户输入非法数字，我们直接用的 `0` 。（这个过程我们放在后面方法的地方再来介绍，让你对 `for循环` 先有一个概念）


## 跳出整个循环

只是 **跳出当前循环** ，你依然是在循环之中。

来试试终结这个循环吧！


### 主动跳出循环

主动跳出循环也是非常方便的。

给前面的 `continue;` ，换成 `break;` 就行了。

``` Csharp

MyConsole.WriteLine("运算符输入有误，没有匹配到对应的计算方式");

// 跳出本次循环
//continue;

// 跳出当前循环
break;

```

现在你要执行程序，继续输出一个非法的运算符，程序可能因为直接跳出 `for循环` 而结束了。

因为你的 `for循环` 下方，并没有书写任何代码，这会导致代码运行完成，程序直接结束。

所以为了不让程序立即结束，我们来做一点小小的改动。

在 for{} 的下方添加两行代码：

``` Csharp

MyConsole.WriteLine($"已经跳出for循环，程序即将结束！");

MyConsole.ReadKey();

```

再次运行程序，输入一个非法的运算符，就会得到：

![break代码演示效果截图](images/c0735270-7bcf-4cca-9a25-cd3fdb628271.png)

此时程序已经跳出 `for循环` ，并且执行 `for循环` 下方的信息输出代码。

因为 `MyConsole.ReadKey();` 代码的缘故，我们随之按下 `任意键` ，程序就会完美结束。


### 循环条件跳出循环

循环条件去跳出循环也是及其简单的逻辑。

目前的循环写法是 `for (; true;)` ，中间这个就是循环条件，它会在每次循环中的代码执行完成之后，重新去判断这个条件。

这在之前的调试中，咱们也清晰的看到过，因为目前一直是写死的 `true` ，所以循环条件永远都满足。

我们可以给它改成一个变量，或者是一个表达式，只要这个变量或者表达式的运算结果是 `bool类型` 的值就行了。

先来定义这个变量：

![定义变量shouldContinue替代循环条件截图](images/ef4b9858-afac-4e1d-a25e-3f0d00b722c3.png)

这里我在开头的位置，定义了 `bool类型` 的变量 `shouldContinue` ，然后把它同步替换到 `for循环` 判断循环是否进行的位置。

这跟之前的逻辑没有任何区别，前面也介绍过类似的概念，在 `C#` 中你直接写 `true` 这种常量内容，本质上也是在给你定义一个变量。

下面我们需要做的就是在收集非法运算符号的时候，改变这个变量，让它不满足循环条件就行了，也就是改成 `false` 。

代码如下：

``` Csharp

MyConsole.WriteLine("运算符输入有误，没有匹配到对应的计算方式");

// 跳出本次循环
//continue;

// 跳出当前循环
//break;

// 修改循环条件，使其不满足循环条件
shouldContinue = false;

```

这时候再来看看运行效果：

![定义变量shouldContinue替代循环条件运行截图](images/f7ef8389-68b6-43bc-be09-ca3652840a20.png)

这里有一点需要注意，目前你看到输出了 `"运算符输入有误，没有匹配到对应的计算方式"` 和 `"第1次计算已经完成"` 这两条信息，代表 `shouldContinue = false;` 这句代码已经执行过了。

按理说这时候 `shouldContinue` 已经 `false` 了，循环应该结束才对呀？ 

**为什么目前卡住了呢？**

还是因为 `MyConsole.ReadKey();` 的原因，我们只需要敲击一下 `Enter回车键` 就行了。

![定义变量shouldContinue替代循环条件完整运行截图](images/f9b81081-e9ae-43cb-8a42-0099f813f3f4.png)

此时就已经能看到 `"已经跳出for循环，程序即将结束！"` 的信息输出了，代表循环已经跳出。

**主动跳出循环** 和 **循环条件跳出循环** 还是有一点区别的。

`break;` 是在当前代码的位置直接跳出循环的，后面的代码就不执行了，所以并不能看到 `"第1次计算已经完成"` 的信息输出。

而改变循环条件 `shouldContinue` 的赋值，仍然要等到这个循环内部代码执行完成，在准备重新验证是否需要继续循环的时候，才会根据 `shouldContinue` 变量的值决定是否继续循环。


## 循环完整结构

目前的循环结构是 `for (; shouldContinue;)` 这样的，只写了中间的部分，缺少了头尾两个部分。

我们其实可以把计数的变量定义 `int calcNumb = 1;` 写在头部：

![calcNumb变量定义移动到循环头部截图](images/ac8551ff-b496-487b-9665-0ceabea51bdd.png)

可以把循环代码每次执行结束对计数自增的 `calcNumb = calcNumb + 1;` 放在尾部：

![calcNumb变量自增移动到循环尾部截图](images/f5c01c93-a74f-4943-9dae-c583943caf4a.png)

这其实就算是还原一个 `for循环` 的完整结构了。

不过需要注意的是，这不是非要这么写的，只是为了容纳一部分代码而已。

正如前面所说的，循环结构更清晰的描述是：

``` Csharp
// ()中的三个部分用 ; 号隔开
for(从哪里开始;到哪里结束;每次怎么变化)
{
    // 需要循环执行的代码
}
```

还有需要注意的点就是：

*  **从哪里开始** ，只会在循环开始之前执行 `1` 次，后续循环是否继续这部分都不会处理了；
* 然后循环 **每次** 结束之后，先执行 **每次怎么变化** ；
* 最后再去判断 **到哪里结束** 的条件。

为了再感受一下这个概念，咱们给出一个 **输出1-100** 的示例代码：

``` Csharp
// ()中的三个部分用 ; 号隔开
for(int i=1;i<=100;i++)
{
	MyConsole.WriteLine(i);
}
```

`i` 从 `1` 开始，到 `101` 结束，每次自增 `1` ;

可以试着调试下这段代码，看看执行效果哦！

> `<=` 小于等于是咱们第一次碰到，此表达式返回一个 `bool类型` 的值， `99<=100 返回 true` ， `100<=100 返回 true` ， `101<=100 返回 false` ；
