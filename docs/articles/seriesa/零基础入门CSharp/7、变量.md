## 变量

**变量是程序中非常非常重要的概念！！！**

这是因为计算机本质上就是在进行数据的 **存/取** ，以及数据的 **运算** 。

在程序运行期间，我们需要指定一块内存区域来存/取数据，这时候就需要 **定义变量** 。


### 类型描述

`C#` 是一门 **强类型** 语言，在进行内存区域申请，或者说变量定义的时候，需要规定这块区域存放数据的类型。

比如可以用 `int` 来标识这块区域只能存储 `整数类型` 的数据， `string` 来标识这块区域可以存 `字符串类型` 的数据...

当然，变量的类型也不止上面描述的这两个，这里也不准备做个表格展示，来描述哪个变量类型对应哪个数据。

百科全书你用的时候自己再慢慢看吧。

主要还是因为，后续的内容就是在围绕 `int` 和 `string` 。

**其实可能还有一个 `bool` 。**

> 变量类型是关键字哦，可不能写错了。 `int` 不是 `itn` ， `string` 不是 `srting` ， `bool` 不是 `boll` 。

## 变量定义

定义变量的格式非常简单，大体可以分为 **指定初始值** 和 **不指定初始值** 。


### 指定初始值

先来看 `指定初始值` 的。

``` Csharp
变量类型 变量名称 = 变量值;
```

其中 `变量类型` 是关键字，上面也介绍过，你动不了的，严格按照要求来。

`变量名` 是我们自己取的，可以认为它是这块内存区域的别名，后面我们通过这个名字来访问这块区域。

> 取名字的规则和我们之前描述一致，`123` 、 `1234number` 、 `my number` 这样都是不行的。

`=` 我们虽然读作 **等于号** ，但是它 `不是表示相等` ，而是 `表示赋值` 。

意思就是把 `=` 右边的计算结果， **赋值** 给 `=` 左边的变量。

> 判断是否相等，需要用到双等号 `==` 。

`变量值` 也是按照需求来的，没有需求就随便来。

**每一句代码都要以英文的分号结尾;**

此时要想申请一个存放 **整数** 的内存区域，就需要定义一个变量。

格式就是：

``` Csharp
int 随便取一个名字 = 666;
```

你没看错，我定义了一个 `int` 类型的变量，并且变量名称就叫 `随便取一个名字` 。

> 可以描述成，把 `666` 赋值给 `int` 类型的变量 `随便取一个名字` 。

很好，下面再来定义一个其它类型的变量：

``` Csharp
string lalala = "你好啊，这是丑萌气质狗的C#文章";
```

定义 `string` 类型的变量的时候，要注意一下了！

`变量值` 需要有一点修饰，明确它真的是一个 `string` ，需要用 `""` 来囊括住字符的内容。

``` Csharp
string lalala = 666;
```

要是像上面这么写就会导致代码报错。

![VS启动页项目预览截图](images/d36e7a88-e6b4-4d27-80f3-a89dc0a42201.png)

这里就会提示错误信息 **无法将类型"int"隐士转换为"string"** 。

这是因为直接写 `666` ，编译器会认为这是一个 `整数` 类型的数据，但是左边定义的变量类型是 `string` ，是字符串类型的，两边数据类型不一致，所有就报错了。

> 如此可见，在 `C#` 中，我们要严格按照类型的关系来操作，后面的运算也会遇到类似的问题。


### 不指定初始值

看了手动指定初始值的定义之后，再来看不手动指定初始值就会发现无比简单。

格式是：

``` Csharp
变量类型 变量名称;
```

不需要写 `=`，直接分号结尾就行了。

不建议大家用这种方式来定义变量，只要你定义了，就一定记得要初始化。

**没有显式指定初始值，不代表变量没有值。**

在某些情况下，比如咱们的 **成员变量** ， `C#` 会自动为它提供当前类型的默认值。

比如 `int` 类型的默认值就是 `0` 。

`string` 类型的默认值就是 `null` 。

> 这里的 `null` 也是一个很有意思的值，它表示"没有引用任何对象"。不是数字 `0` 也不是 `""` 这样的空字符串。
