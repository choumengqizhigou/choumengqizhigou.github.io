前面也说过，定义变量，只是为了申请一块内存区域，进行数据的存储。

那么现在已经存好了这些数据，就需要利用它们计算得到期望的结果。

最简单的运算，当然是数学运算了。

## Main方法回顾

前面已经了解到， `Main方法` 是程序的入口 **方法/函数** 。

程序从`Main方法` 的 `{` 开始， 然后一行代码一行代码的执行，直到 `Main方法` 的 `}` 结束。

所以接下来我们代码只要写在这个范围内就可以了。


## int类型变量计算

为了做整数计算，我们很快就能定义好几个整数变量。

``` Csharp
class Program
{
	static void Main()
	{
		int num1 = 100;
		int num2 = 200;
		int sum = 0;
	}
}
```

先来定义三个 `int` 类型的变量，它们的名字分别叫做 `num1` `num2` `sum` ，里面存储的值分别是 `100` `200` `0` 。

下面先来做一个最简单的 `加法运算` 。

> 数学运算在编程中很常见，日常使用的 `加减乘除` 在 `C#` 中分别对应 `+ - * /` 。

``` Csharp
class Program
{
	static void Main()
	{
		int num1 = 100;
		int num2 = 200;
		int sum = 0;

		sum = num1 + num2;
	}
}
```

这样的代码写完，应该是有必要做几点解释的。

先来描述几个概念，然后再来解释一下代码吧！


## 局部变量、成员变量

我们对变量有过描述，当时特意强调： **定义变量就一定要记得及时初始化** 。

也说明过存在一个特殊情况，就是 `成员变量` 如果不给初始值，会使用当前类型的默认值。

很显然，疑问也随之而来。

**什么是局部变量？**

**什么又是成员变量？**

**不给初始值又会发生什么？**

看似描述很多，问题也很多，其实几句话就能说完。


### 局部变量

**在方法内定义的变量叫做局部变量！**

这里我们在 `Main方法` 的 `{}` 中定义的几个变量都是局部变量。

如果我们取消一个局部变量 `num1` 的赋值，就会得到如下错误：

![局部变量未赋值报错截图](images/82eaa0b9-0cfd-4a5b-83af-cc34d9fb4bca.png)

告知我们 **使用了未赋值的局部变量"num1"** 。


### 成员变量

**在方法外定义的变量叫做成员变量！**

> 你看到的一些什么字段、属性都可以叫做成员变量。

对于上述的错误，我们可以不给 `num1` 赋值，并且还不会报错。

![成员变量定义截图](images/cbbbde17-1623-4ff2-9a5d-2d4bfbed50d9.png)

只需要把 `num1` 的定义挪到外部，这样就不会报错了。

> 只不过我们加了一个额外的 `static` 修饰符。这是因为 `Main方法` 的特殊性，后面介绍类型的时候再来进一步描述为什么要这样。

所以对于 **成员变量** 来说，下面是一个意思：

``` Csharp
int num1;
// 等同于
int num1 = 0;

string name;
// 等同于
string name = null;

bool isChouMengQiZhiGou;
// 等同于
bool isChouMengQiZhiGou = false;
```

### 成员变量的作用域

成员变量的定义和使用要宽松的多。

**成员变量只要在方法外定义了，基本当前类所有地方都能访问，也不关心代码顺序。**

``` Csharp
class Program
{
	static void Main()
	{
		// 可以访问 num1，不可访问 num2
	}

	// 定义静态成员变量num1
	static int num1;

	// 定义成员变量num2 也可以访问 num1
	int num2 = num1;

	void MyFuntion()
	{
		// 可以访问 num1和num2
	}
}
```

> 这里为了能够在 `Main方法` 中访问成员变量，依然是使用了 `static` 来修饰，类型部分来解释。

## 回归代码解释

先来贴一下目前的代码：

``` Csharp
class Program
{
	static void Main()
	{
		int num1 = 100;
		int num2 = 200;
		int sum = 0;

		sum = num1 + num2;
	}
}
```

现在看不懂代码依然是正常的，但是相信你应该会更容易看懂下面的解释。

**`Main` 是入口，代码是自上而下逐行执行的。**

前三句代码，已经非常容易了。

暂时理解为就是申请了三块内存区域，用来存放 `整数` 数据的。

三块内存区域的名字分别叫 `num1` `num2` `sum` ，里面存储的值分别是 `100` `200` `0` 。。

第四句才是今天的重头戏，前面描述这么多，其实就是在为它服务的。

作用域中咱们知道，已经定义好的变量，在可用范围内，就能直接通过 **变量名** 访问这块内存区域的值。

所以 `num1 + num2` 就容易理解为 `100 + 200` 。

可是如果按照上面这么理解，那么整个整句代码翻译过来不就是：

``` Csharp
sum = num1 + num2;
↓
0 = 100 + 200;
```

很显然，这样的改变你我都不能接受。

所以咱们还是忽略了一个符号，那就是 `=` 。

前面其实也说了， `=` 是赋值运算符，它会先计算右边的表达式，再把得到的结果赋值给左边的变量。

所以这里的翻译应该变成：

``` Csharp
sum = num1 + num2;
↓
sum = 100 + 200;
↓
sum = 300;
```

描述就是：把 `num1` 和 `num2` 两块内存区域的值，取出来进行加法计算，然后把值写入到 `sum` 的内存区域中。

所以 `sum` 所代表的内存区域，里面存储的值就应该从 `0` -> `300` 。

> 对于已定义的变量，访问变量名是取出值还是写入值，暂时只看一点，就是变量名称在 `=` 左边是写入值，其它通通都是取出值。
