## 循环信息

**循环** 不是什么神奇的时候，目前它只是在重复执行我们写好的一段计算过程。

很多时候，我们往往会统计一些信息，比如 **当前计算是第几次计算** ， **一共执行了多少次计算过程** ，甚至是 **统计每一次的计算过程和计算结果** ... 

这些都是可以通过定义变量来逐个记录的，毕竟变量它就是干这个事情的。

这么我们就不做过多的统计了，只做一个简单的统计。

**打印出当前计算过程是这个循环的第几次！**


### 记录循环次数

做这个功能，真的非常简单！

只需要定义一个 `int类型` 的变量，初始值给一个 `1` ，然后每次执行到循环末尾的时候，让这个变量值 `+1` 即可。

只是唯一需要注意的就是这个 **变量的范围** 。

一定要定义在 `for{}循环` 的大括号外面。

这其实也没什么好解释的，如果你真像下面这么定义：

![演示错误定义变量calcNumb](images/dd13e1b6-d664-4a6a-af1a-2088e0c4a258.png)

那么，就会导致每次循环，你都在重新定义这个 **局部变量** `calcNumb` ，当本次循环走完，这个 **局部变量** 也会同步被销毁，它的初始值也永远是 `1` ，即使你改变了这个值，也无法保留到下一次循环，因为下一次循环就没有当前循环这个 **局部变量** 了。

> 这里其实也会让人产生一个新的疑惑，循环每次都执行，我一直这么定义同一个名称的变量，难道不是有问题么？
> 看来你真的有在考虑一些事情，这让我很佩服！但是这里不需要有过多的解释，唯一需要知道的是，每一次的循环执行，代码范围都是独立的。
 
为了让每次循环，都能对同一个变量进行次数的统计，咱们决定把变量的定义放在 `for循环` 的上方。

就像这样：

![演示正确定义变量calcNumb](images/001100bc-1a19-4e58-98aa-1296135efde2.png)

这样定义好变量之后，只需要在每次循环执行完成之后改变它的值，让它的值 `+1` 即可。

到时候咱们就能通过这个变量里面具体的值，来知道当前循环执行了多少次。

改造方法也是很简单：

![变量calcNumb自增截图](images/ff691490-9f12-4be3-a509-9dd5236d383c.png)

直接去到 `for循环` 代码范围的最后，写上 `calcNumb = calcNumb + 1;` 这句代码即可。

**书写位置也一定要注意，循环范围内修改变量次数，千万不能写到循环外部！**

这句代码相信你应该也不陌生，前面有专门解释过。 `=` 号右边的 `calcNumb` 表示取值，第一次值是 `1` ，然后计算 `1+1=2` ，把计算结果 `2` 重新赋值给 `=` 号左边的 `calcNumb` ，下一次循环 `calcNumb` 值就是 `2` ，同样执行上述逻辑过程就会得到 `3、4、5、6...` 。

> 像这样使变量自增的写法还有很多，就像是 `calcNumb += 1;` 、 `calcNumb++;` 、 `++calcNumb` 这些，跟我们的 `for循环` `while循环` ...一样。有类似逻辑的内容，往往不需要全部掌握，甚至都没必要全部过一遍。有了开发的主线流程和概念之后，就应当从自身框架出发，用已经掌握的技术去填充需要完成的内容，过程中遇到问题、没见过的知识、语法，再去定向了解，积累经验，也更能加深对技术的记忆和运用。
> 这其实也变相在说明，一个快速入门的主线框架至关重要，这也是市面上最稀缺的内容。尤其是在AI这么发达的时代，对这样内容的渴望达到了顶峰，因为AI成为了那个帮你扩充分支的最好导师！完全没有必要去遵循什么1000集、10000集...从入门到精通、系统性学习xxx这样的鬼才逻辑，这种鬼才操作真的就跟让你在学习语文之初，背诵新华字典一样荒谬，至少这不是一个适合大部分人的方式！


### 打印循环次数

现在咱们已经通过变量 `calcNumb` 来记录当前执行的第几次循环。

**但是！**

众所周知，代码也好，数据也好，它不是不会主动告知你，我代表的含义是什么，我的值现在是多少。

一切都需要咱们显式的标注出来。

好在学了调试之后，你是能主动追踪这些内容的，看看它到底是怎么执行，怎么变化的。

> 从这里你已经能感受到，代码只是一种工具，一种手段。同样是 `int类型` 的变量，它既可以表示我们计算的数字，也可以表示身高、体重，甚至是游戏角色的生命值。
> 一切的一切，取决于你如何将自己的业务和行为操作进行信息化的改造。

**一起来调整一下信息输出吧！**

先来看一下原先计算完成的输出信息：

![计算完成输出信息截图](images/2b74730a-73c6-40fc-ac27-fcbf6fda2854.png)

原先计算完成之后，我们会直接输出固定内容 `"计算已经完成"` 。

我们想要查看当前循环执行的第几次，直接在原先输出的下方，补上一句 `MyConsole.WriteLine(calcNumb);` 就行了。

![输出calcNumb变量值截图](images/3ca7467a-03b0-4733-b40c-70f8f458b8a4.png)

这样你在执行计算过程的时候，就能清晰的看到具体的数值了：

![输出calcNumb变量值运行演示截图](images/90c99cc3-28ac-44f5-91be-4d583979249e.png)

非常的完美！

这跟之前咱们验证第一个数字的值的时候，做的方式是一样的，直接输出变量值。

只是很显然这样的结果并不适合作为通用展示，毕竟你冷不丁这么来一个信息的输出，谁知道你要干嘛呀。

所以我们需要改造一下，最好是把 `"计算已经完成"` 调整为 `"第x次计算已完成"` ， `x` 表示当前 `calcNumb` 中的值。

**如果你是第一次接触程序，就会发现这个地方已经开始有点难倒我们了！**

因为原先我们要么是全静态内容的输出，要么是动态变量的直接输出。

如果你改造成 `MyConsole.WriteLine("第calcNumb次计算已经完成");` 这样的代码输出：

![静态输出calcNumb变量值演示截图](images/054ab478-99b3-4238-8379-180b6806a8d6.png)

得到的结果就是全静态的内容 `"第calcNumb次计算已经完成"` ：

![静态输出calcNumb变量值演示截图](images/adaf0a08-d548-4a5a-bd48-fe46a63f4950.png)

毕竟 `""双引号` 表示的就是字符串，这么写就是原样输出字符串。

**那就来看看：变量和字符串的拼接！**

操作起来也是非常简单，直接用 `+` 号连接就行了。

直接写改造方案了哈！

``` Csharp

MyConsole.WriteLine("第"+ calcNumb + "次计算已经完成");

```

一共三个部分，`"第"` ， `calcNumb` ， `"次计算已经完成"` 。

其实也可以理解为三个字符串变量的拼接：

``` Csharp

//等同于上述代码
string str1 = "第";
string str2 = "次计算已经完成";
MyConsole.WriteLine(str1 +calcNumb + str2);

```

所以看到的最终效果就变成了：

![字符串拼接calcNumb运行演示截图](images/9b8e583d-b5d0-4593-8019-35e1ee271866.png)

**这样就算是完美展示了！**

> 这里可能有一个疑惑， `calcNumb` 是 `int类型` ，但是 `"第"` 和 `"次计算已经完成"` 却是 `string类型` ，那不就变成了 `int + string` 了么。前面也说过了，不同类型的变量计算，一定要转换成同一类型，而且 `int` 怎么能和 `string` 相加呢？
> 这里就是一个新的内容，叫做运算符重载。在 `C#` 中，默认定义的 `int + string` ，会把这个 `int` 转换成 `string` 。这里的逻辑其实是 `"第"+ calcNumb.ToString() + "次计算已经完成"` ，让 `calcNumb` 调用 `ToString()` 方法，转换成 `string类型` ，即 `1 -> "1"` 。（ **其实我们也可以创建类型,自己来定义 `+` 号的行为，有兴趣可以搜搜看** ）

除了上述这种字符串拼接的写法以外，还有一种拼接方式会显得更加合理一点。

``` Csharp

//MyConsole.WriteLine("第" + calcNumb + "次计算已经完成");

MyConsole.WriteLine($"第{calcNumb}次计算已经完成");

```

就是这样 `$""` ，在 `""` 双引号前面添加一个 `$` 美元符号。

> `$` 美元符号用组合键 `shift + 上方数字4` ，如果打出 `￥` 人民币符号，则需要调整下 **中英文输入法** 。

这样就不需要把字符串拆分成多个部分，并且写上多个 `+` 号了。

只需要在拼接变量的地方，套一个 `{}` 大括号，把变量写进去就行了。

这种方式拼接也更加直观一点，特别是要进行多个变量拼接的时候，也更不容易出错。

甚至还可以这么写：

``` Csharp

MyConsole.WriteLine($"第{calcNumb}次计算{"已经完成"}");

```

因为你时刻要记得，这些直接在代码中书写的常量： `1` 、 `"1"` 、 `"丑萌气质狗"` ...

它们都代表这一个指向内存空间的变量，只是直接这么写，变量不是由你主动来定义了，而是编译器帮你处理了这部分。可能它的变量命叫做 `abc7788345` 。

> 还有就是，就算是你自己定义的变量，比如 `int a = 1;` ，这个名称变量 `a` 也只是编写代码阶段你自己用的，编译器在处理的时候，其实是会给它重新安排一个名称，比如类似于 `cds909088` ，当然这并不是什么重要的概念或者内容，瞎聊聊而已。
