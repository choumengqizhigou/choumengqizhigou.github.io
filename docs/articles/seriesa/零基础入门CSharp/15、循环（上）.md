目前的程序已经是非常完美了，短短几行代码，就拥有良好的用户交互、完整的计算功能、异常的错误捕获。

但是目前唯一美中不足的是，这样一个程序是一次性的，并不能持续的运行下去。

每次运行结束之后，程序就会关闭，想要再次使用计算功能，需要重新运行程序。

**那有什么办法能够使得程序一直在运行呢？**

这里没有什么特别的方式，咱们的程序就是一句一句代码构成的，当前写的这几句代码就够支持一次计算的。

所以想要让程序进行第二轮计算，就需要把已有的代码流程，复制一下，然后粘贴到第一轮代码的下面。

这样等第一轮代码执行完成之后，就会开始第二轮计算，重新获取第一个数，第二个数。

以此类推，复制几次就会执行几轮，第三轮、第四轮、第五轮...第N轮。

这么看来，只要我复制的足够多，比如先复制个 `500` 遍代码，用户用起来就感觉这个程序在一直运行。

**毕竟谁会连续使用计算器500次呢！**

真要是这么玩，那写代码真的是个体力活。

很显然有更方便的方式， `循环` 就是我们对这种重复执行的问题给出的答案！



另外咱们的获取数字的错误处理也是一样的，获取数字的流程也只有一次机会。用户输入正确的这是没毛病的，但是用户一旦输入错误了，你获取到的就是 `0` 。

## 循环

想要让一段代码不断执行，直接套一个 `循环` 就行了。

`循环` 的语法有好几种，比如 `for` `foreach` `while` `do while` ，它们的作用都有点类似，部分用法上也有点区别，这里我们不对每个都进行介绍，只看一个 `for` 。


### for语法

`for` 的语法还是比较麻烦的，特别是第一次接触的时候，因为它本身设计是按照多个部分来。

比如， **从哪里开始** 、 **到哪里结束** 、 **每次怎么变化** 。

用伪代码来表示就是：

``` Csharp
// ()中的三个部分用 ; 号隔开
for(从哪里开始;到哪里结束;每次怎么变化)
{
    // 需要循环执行的代码
}
```

咱们只需要把需要重复执行的代码，套在 `for(){}` 的大括号范围内就行了。

> 伪代码：不是可以执行的真正代码，只是用代码结合自然语言，或者其它一些的形式来表达一些思想和步骤，方便表达开发逻辑以及给别人演示。

**`for循环` 的语法虽然分成了好几个部分，但其实每个部分并不是必须的。**

这个结构是可以进行简化的，你只需要知道 **到哪里结束** 这个部分是一个 **bool类型的值** ，其它两个部分都可以不写。

当代码执行到 `for循环` 的时候，会先判断这个 **bool类型的值** ，如果是 `true` ，就执行 `for(){}` 大括号范围内的代码，如果是 `false` ，就直接跳过整个 `for(){}` 大括号的结构范围。

**上面描述的逻辑是第一次要执行 `for循环` 的时候。**

第一次如果是 `false` ，会直接跳过整个 `for循环` 的结构，继续执行下面的代码，并且再也不会回到这个循环了。

这没什么好说的，相当于你并不需要执行这一块的代码，跟 `if` 的逻辑相似。

可第一次要是 `true` ，则会直接开始执行 `for(){}` 大括号范围内的代码， **然后有意思的就来了** 。

等 `for(){}` 大括号范围内的代码都执行完成了，还会再次判断这个部分的值。如果还是 `true` ，则重新开始执行 `for(){}` 大括号范围内代码。如果是 `false` ，那就跳出整个 `for循环` ，开始执行下面的代码。

**描述语法这种事情，不但枯燥还不够直观。**

就让我们来循环执行一段输出的代码呗：

``` Csharp
// 这里的true也可以不写，不写就相当于默认是true，即默认满足循环条件
for(;true;)
{
    MyConsole.WriteLine("丑萌气质狗！！！");
}
```

上述的代码咱们直接写在 `Main()` 方法开头的位置，仅仅只是作为一个测试。

![for循环演示无限输出文字代码截图](images/77f25c52-a981-4a5a-8b57-55545895138d.png)

这段代码就构建了一个无限循环的代码，直接运行程序的话，会发现程序一直在输出信息： **"丑萌气质狗！！！"** 。

![无限输出丑萌气质狗信息截图](images/bbb2aa6e-5cd2-4b6d-bbb2-9b8e5efff05c.png)

如果你稍微留意一下，会发现当前 `for循环` 下方的代码全部置灰了，并且第一句代码 `MyConsole` 的下方会出现绿色波浪线。

鼠标放上去就会弹窗提示：

![检测到无法访问的代码截图](images/178aa04a-864c-4d16-9171-83ada3e2153e.png)

这是因为上述的 `for循环` 的满足条件一直是 `true` ，所以是一个无限循环，下方代码确实永远也不会执行。

### 改造计算代码

前面咱们已经能构造一个无限次数的循环了。

想让之前的计算程序一直运行下去，只需要把所有计算的代码嵌套到 `for(){}` 的大括号范围就行了。

执行起来也是非常简单的。

![移除for循环结束大括号截图](images/e40c2403-2287-4bee-a755-84161d63f1f8.png)

把已经写好 `for循环` 的结束大括号删掉。

![代码最后补充for循环结束大括号截图](images/72649410-aedf-4861-bf83-e5ba43a4476e.png)

然后拉到代码最下层，补上一个 `}` 大括号即可。

当然你也可以把之前所有的代码都 **剪切** 进这个 `for循环` 的大括号范围内，这个随便你。

> 这么操作你会发现，代码的格式乱了，默认的格式，可能是 `{`大括号的内部代码要缩进一部分。
> 想要重新格式化代码，就依次按 `Ctrl K` 和 `Ctrl D` 。

重新格式化一下代码，按下 `Ctrl K + Ctrl D` 。

![格式化代码之后截图](images/00014252-0c67-4f0c-b1c7-1d9df548f22d.png)

**代码格式之后，看起来确实会舒服一点！**

现在直接运行代码，咱们的代码流程就会变成：

* 收集第一个数字；
* 收集第二个数字；
* 收集 `+ - * /` 运算符；
* 输出计算结果；
*  **敲击回车** 之后，重复执行上述步骤。

![演示循环计算截图](images/2a11b750-2cad-4c5b-b224-c9f87da029c6.png)

**这里可以思考一下，为啥最后需要敲击回车才会重头再次开始！**

其实也没啥好说的，毕竟输出 `计算已经完成` 信息之后，写了一句获取用户输入的代码。

``` Csharp
...
MyConsole.WriteLine("计算已经完成");

// 等待用户输入
MyConsole.ReadKey();
...
```

当初是为了阻止程序结束，防止看不到最终的结果，才加的 `MyConsole.ReadKey();` 这句代码。

现在因为我们计算在一个循环里面，一次计算完成可以快速进行下一次计算，所以删掉这句代码也是可以的。
