代码的结构其实还是比较清晰的，目前 `VS` 提供的 **预制代码** 分为上下两层。

上层的 `using` 和下层的 `namespace` ，这两个算是强相关的。

`namespace` 用来表示地址， `using` 就是用来找这个地址的。


## 注释

开始写代码之前，补充一个 `注释` 的概念。

前面说过 **编译器** 会 `编译` 我们的代码，但是写了注释的代码会直接被忽略掉。

``` Csharp
    //Console.WriteLine("这是我的第一句代码");
    Console.ReadKey();
```

如果在之前的代码前面写上两个斜线 `//` ，那么运行程序的时候，就无法看到 `这是我的第一句代码` 这段文字了。

`//` 不仅可以注释代码，它可以注释任何文本，意思就是让 `编译器` 直接忽略这一行文本的存在。

比如：

``` Csharp
    //下面是一段输出文本的代码
    Console.WriteLine("这是我的第一句代码");
    Console.ReadKey();
```

如果不写 `//` ，直接在代码里面写上字符，跟上一节随意写字符 `666` 一样，代码就会直接报错。

最后就是注释分为 **单行注释** 和 **多行注释** 。

**单行注释**就是每一行的开头直接写 `//` 。

``` Csharp
    //注释1
    //注释2
    //注释3
    Console.WriteLine("这是我的第一句代码");
    Console.ReadKey();
```

**多行注释**就是 `/*` 开头 `*/` 结尾。

``` Csharp
    /*注释1
    注释2
    注释3*/
    Console.WriteLine("这是我的第一句代码");
    Console.ReadKey();
```


## 代码格式说明

`{}` 是描述代码的范围，目前的范围分为内外三层。（ **using部分暂且不看** ）

``` Csharp
namespace FirstCode
│
│  
└─internal class Program
    │
    │  
    └─static void Main(string[] args)
```

仔细观察大括号的范围，是一层一层嵌套的。

``` Csharp
namespace（命名空间/名称空间）
{
    class（类型）
    {
        Main（方法）
        {

        }
    }
}
```

这是一个代码的常规结构， `命名空间` 下有 `类型` ， `类型` 下有 `方法` ，并且是 **一对多** 的概念，目前这里是 **一对一** 。

**就当前这个代码结构，还可以进行缩减。**

既然暂时不看 `using` ，干脆连着 `namespace` 也先一并忽略，暂时它们不影响最终的运行结果，而且前面也稍微描述了一下它们之间的关系，两个是相辅相成的东西。

``` Csharp
class（类型）
{
    Main（方法）
    {

    }
}
```

所以最简洁的结构就变成了 `类型` 嵌套 `方法` 。

另外就是 `internal` 属于 `class` 的一种修饰， `string[] args` 属于 `方法` 的一种修饰，都可以先移除掉。

``` Csharp
class Program
{
	static void Main()
	{
	}
}
```

这样的代码虽然精简了一点，但同样是一个正确的结构，自然也是可以正常运行的，只不过是一个空架子，可能刚运行程序，就结束关闭了。

### 名称与关键字

前面了解到代码的结构是逐级嵌套的，为了描述清楚你代码中的概念，就需要给每个结构部分附带一个名称。

| 结构 | 代号 | 名称 |
| ---- | ---- | ---- |
| namespace FirstCode | 命名空间/名称空间 | FirstCode |
| class Program | 类型 | Program |
| static void Main() | 方法 | Main |

上述部分可以认为是 `关键字` 和 `名称` 两个部分构成的。

其中 `关键字` 就是 `编译器` 认识我们代码结构的锚点，必须一字不差的正确书写。比如 `namespace` 、 `class` 、 `static` 、 `void` 。

> `关键字` 也不止这些，不过也不必担心，常用的就是十来个。**

而结构所对应的名称是属于 `"玩家"` 自定义的，你想写什么名字就写什么名字。

这里有一个特殊就是，方法名字也是自定义的，但是 `Main` 除外。

**等会来说它。**

既然名称是随便输入的，那我就不客气了。

> 因为 `namespace` 被我们上一节删掉了，所以修改名字没用 `namespace` 举例了，不过它的名字也是随意更改的。

修改成这样：

``` Csharp
// namespace前面被删了，这里就不演示改名了
class Program666
{
	static void Main()
	{
	}
}
```

或者这样：

``` Csharp
// namespace前面被删了，这里就不演示改名了
class gagaga999
{
	static void Main()
	{
	}
}
```

因为 `C#` 对中文支持不错，甚至可以是这样：

``` Csharp
/* namespace前面被删了，这里就不演示改名了 */
class 阿猫阿狗
{
	static void Main()
	{
	}
}
```

> 对于名字的书写没有特别多的要求。
> 但是不要写成纯数字、或者是数字开头，比如： `999999` 、 `666Program` ，这些都是会导致报错的。
> 同时名字中间也不要有空格，比如： `First Code` ，如果真想区分可以用下划线连接，类似于： `First_Code` 。


## Main方法

方法的名字也是可以自定义的。只是 `Main` 是一个特例。

**这是一种约定， `Main` 方法是程序的入口方法。**

代码的执行顺序就是从 `Main` 方法的 `{` 开始，到 `Main` 方法的 `}` 结尾结束。

所以一开始咱们演示代码的时候，写的两句代码就是在 `Main` 的 `{}` 括号范围内。

**所有代码必须直接或者间接的写在 `Main` 方法的范围内。**
