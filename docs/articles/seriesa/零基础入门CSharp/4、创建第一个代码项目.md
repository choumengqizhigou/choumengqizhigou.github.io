开发工具已经具备了， 下面就开始愉快的写代码吧！

之前的演示如果你还记得，咱们手动创建了一个 `代码文件` ，然后编写代码，巴拉巴拉...

现在不需要这么麻烦了，预制菜听过，下面也要听听预制代码的故事了。

在 `VS 2022` 中，我们可以在提供的 `项目模板` 中去挑选一个模板，然后输入一些信息： `项目名称` 、 `存放路径` 、 `平台版本`... 再点击创建， `VS` 会给我们预生成一些代码相关文件。

让我们来操作一遍呗。


## 创建第一个Console程序

`Console` 程序是一个只有黑框框的程序，之前演示的就是一个 `Console` 程序。

后续我们还有很多其它 `项目模板` ，像客户端界面程序、网页程序啥的。

**流程走起！**

![VS 2022软件菜单](images/db92e48d-a81e-4363-85d8-a829989abf7d.png)

打开我们的 `VS 2022` ，注意是 `Visual Studio 2022` ，不是 `Visual Studio Install` ，后者之前已经介绍过了，就是用来管理 `VS版本` 以及 `修改VS组件` 的。

![VS 2022启动界面](images/612ef7b2-ddfd-48f2-aae0-2f171b6fd586.png)

可以看到界面左边是 `打开最近使用的内容(R)` ，说的很详细了，就是操作过的内容，都会在左边作为一个历史记录，供你快速打开访问的。

![创建新项目示例截图](images/cb4c04ff-4eb8-4418-9837-a980af524b2f.png)

我们点击右边的 `创建新项目(N)` 即可。

![创建新项目界面](images/e30276a0-363c-407b-9a9d-d631577a6d77.png)

来到 `创建新项目` 的界面，又是左右结构，右边就是 `项目模板` ，左边是创建过的 `项目模板` ，也是历史操作记录，供你快捷操作的。

![选择语言C#](images/d8d40a59-2417-40c8-9a75-a259127e9e43.png)

这里语言选择 `C#` ，然后翻到下面找到 `控制台应用（.NET Framework）` 这个项目模板。

![20230519095305](images/fcfdc254-7837-4b54-9e39-a170f63673ce.png)

创建的时候稍微注意下， `控制台应用` 和 `控制台应用（.NET Framework）` 这两个模板。

**控制台应用使用的是 .NET Core ，建议按照图例 .NET Framework 来！**

> 关于 .NET 平台，其实经历了几个阶段（这里以 C# 为例）。
> 开始的是 .NET Framework，它主要支持 Windows。后来，社区发起了 Mono 项目，实现了一套跨平台的 .NET 运行时，让 C# 可以运行在 Linux、macOS 等系统上。再后来，为了正式支持跨平台，微软自己推出了 .NET Core ，并从零开始重新设计了新的跨平台运行时 CoreCLR。

选择好 `控制台应用（.NET Framework）` 后，点击 `下一步` 。

![配置新项目界面](images/e9670b7f-6a28-4e9d-bde9-3df441bad938.png)

现在我们需要给我们的项目取一个名字，并且指定创建的这个项目要放在哪个文件夹下。

还有一个叫做 **解决方案名称** 的名称，它会随着 **项目名称** 一同变动，不过你也可以单独对它进行更改。

![修改解决方案名称为AllCsharpCode](images/3704d7c9-28b8-4b1f-bf80-2aadf41dcb8e.png)

为了更好的说明，这里将 **解决方案名称** 改为 `AllCsharpCode` 。

最后要设置的就是 **框架** ，这就是 `.NET平台` 的版本选择。

![新项目最终配置截图](images/c480e4d6-8481-44f4-85af-ddc16e051cdd.png)

目前 `.NET Framework` 最终一个大版本就是 `.NET Framework 4.8` ，这里就选择 `4.8` 。

点击 `创建` 。（**选择其他版本不影响后续的教学内容**）

## 项目文件结构介绍

首先要搞清楚的就是创建的 **项目** 到底是什么？

其实 **项目** 就是 **文件模板** ，在创建的时候，不是选择了一个保存路径 `D:\Csharp\` 么。

**现在就去一探究竟！**

![Csharp文件夹截图](images/beb9a83c-7ce8-4fdb-aceb-0564b1706470.png)

来到 `D:\Csharp\` 目录下，可以看到一个这里多出了一个 `AllCsharpCode` 文件夹。

![AllCsharpCode文件夹截图](images/584bf767-f7b5-4857-a189-4030c28261fb.png)

然后进到 `AllCsharpCode` 文件夹中可以看到 `FirstCode` 文件夹和 `AllCsharpCode.sln` 文件。

![FirstCode文件夹截图](images/7d63229c-2f4c-4c80-8194-7cc87f771721.png)

继续深入到 `FirstCode` 文件夹，又能看到一些文件，后面就不继续深入了。

这里不知道你有没有眼熟一个文件，那就是 `Program.cs` ，这就是代码文件，如果你用记事本打开它。

![记事本打开Program.cs](images/6bfe1353-0660-4761-90ed-d784d0f7c8ce.png)

可以看到它与我们 `VS 2022` 中展示的是一样的内容，所以 `VS 2022` 默认编辑展示的就是这个代码文件。

**整体项目的文件结构大概是这样的：**

```
AllCsharpCode
    ├─AllCsharpCode.sln
    │  
    └─FirstCode
        ├─App.config
        ├─FirstCode.csproj
        ├─Program.cs
        │  
        ├─bin
        │  └─Debug
        ├─obj
        │  └─Debug
        │      │  .NETFramework,Version=v4.8.AssemblyAttributes.cs
        │      │  DesignTimeResolveAssemblyReferencesInput.cache
        │      │  FirstCode.csproj.AssemblyReference.cache
        │      │  
        │      └─TempPE
        └─Properties
                AssemblyInfo.cs
```

这是我们新建一个 **项目** 时所生成的目录结构，可能看着挺复杂。并且随着你的使用，这些目录里面还会自动生成一些其它文件。这些都是用来协助 `VS 2022` 管理项目代码、存放编译参数或者编译过程中产生的文件。

如果此时你回到 `VS 2022` 里面，就会觉得文件结构清晰了很多。

![解决方案资源管理器截图](images/d90c481e-7758-4deb-bd6d-602f155f64bd.png)

右侧的 `解决方案资源管理器` 中，暂时只需要关心 `Program.cs` 代码文件即可。很多设置选项，暂时都还用不到，或者说，已经有了默认值，暂时没有特殊需求，还无需更改这些默认值。

> 如果没有解决方案资源管理器这个页面。可以在上方菜单中操作打开。
> 视图(V) -> 解决方案资源管理器(P) 。

## 创建项目说明

1. 创建建 **项目** 就是创建 **文件模板** ；

2. 解决方案名称与项目名称，分别对应了文件夹的名称；

3.  `.sln` 文件是 `VS 2022` 的解决方案文件，它里面存储了一些信息来帮助 `VS 2022` 寻找对应的项目，双击它也可以打开我们的项目；

4. 一个解决方案可以有多个项目，对应到文件夹中就是 `FirstCode` 项目一个文件夹， `SecondCode` 项目另外一个文件夹，但是它们都在 `AllCsharpCode` 这个文件夹的下方；（**后面也会演示创建多个项目**）

5. 还有一个文件也可以打开我们的项目代码，就是 `FirstCode` 文件夹下的 `FirstCode.csproj` 文件，这个就是当前这个项目的管理文件，双击也可以打开项目；

## 写上代码并运行

下面需要你跟着操作一下，把两句简单的代码 `复制到VS 2022` 里面。

如果你的代码没有打开，或者不小心点到其他地方去，导致看不到代码内容，你可以双击右侧 `解决方案资源管理器` 界面中的 `Program.cs` 。

**如果右侧展示解决方案、项目的窗口都不见了，那确实很悲催。直接参考下图打开。（其他窗口不见了，也可在 `试图(V)` 菜单中找到）**

![演示在菜单中打开解决方案资源管理器截图](images/27f35368-6f4c-4537-bc8c-ecd4df378377.png)

代码直接复制就行了。

``` Csharp
Console.WriteLine("这是我的第一句代码");
Console.ReadKey();
```

![演示代码书写位置截图](images/1d5519c9-9f7a-4915-af97-cf24f9e210d4.png)

> 注意代码复制的位置，一定要在 `{ }`的范围内，同时也要注意每句代码后面会有一个 `分号` 。

![演示代码提示截图](images/bd55a4e9-196b-4b2b-9cbf-5f3de5046353.png)

如果你有兴趣手敲的话，还可以看到敲击字符之后，是会有 **代码提示** 的，用鼠标点击提示内容的话，提示内容也会直接被应用在编辑里面。

完成两句代码的书写之后，就可以运行代码了。

![运行按钮截图](images/5f6f084e-a50d-4797-9ac7-3db5267cc336.png)

![代码运行最终效果](images/ab645b16-eee1-45b6-bd54-826400853eeb.png)

点击上方 **绿色三角形** 的 `启动` ，应该可以看到一个黑色的框框，里面有一段文字输出。
