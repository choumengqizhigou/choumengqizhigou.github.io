## 信息接收

现在的代码已经能进行 `加法运算` 了。

主要的弊端也很明显，就是参与计算的两个数字是写死的。

变更数字就是在变更代码，仍然需要重新编译运行，这其实是很不友好的。

**是否可以让用户来输入这两个数值呢？**

答案不言而喻，让我们开始吧！


### Console.ReadLine()

同样是在 `Console` 类型下面，有一个 `ReadLine()` 方法，能够让用户在黑白框中输入信息。

用户输入完成之后，可以敲击 `Enter` 回车键，代表输入完成，程序代码也能得到用户输入的值。

我们可以在代码中，使用一个 `string` 类型的变量，接收一下这个输入值。

> 为什么要用 `string` 来接收而不使用其它类型？
> 这是我们无法改变的，因为这是 `ReadLine()` 方法的返回值，这部分后续说到方法的时候你就明白了。

前面说的那么多，其实就一句代码的事情，让我来为你表演下这句代码：

``` Csharp
string content1 = MyConsole.ReadLine();
```

> 为了维持上一节代码给 `Console` 重命名为 `MyConsole` ，所以这里依然使用的是 `MyConsole` 。

同时，为了让程序有个友好的互动性，我们可以先进行一个提示语的输出。

那整体代码就变成了：

``` Csharp
using MyConsole = System.Console;

class Program
{
	static void Main()
	{
		MyConsole.WriteLine("请输入要计算的第一个数字：");
		string content1 = MyConsole.ReadLine();

		int num1 = 100;
		int num2 = 200;
		int sum = 0;

		sum = num1 + num2;

		MyConsole.WriteLine(sum);
		MyConsole.ReadKey();
	}
}
```

现在当我们运行程序之后，代码依次从上至下执行。

* 先输出文本： `请输入要计算的第一个数字：` ；
* 再让我们进行输入，直到敲击 `Enter` 回车键，会把用户输入的内容存入变量 `content1` ；
* 再紧接着计算 `100 + 200` ，最终输出 `300` 。

整个过程还是非常清晰的，不过为了验证变量 `content1` 是否真的获取到了用户输入的信息。

可以紧接着在它的下一行代码加一句输出信息：

``` Csharp
...
string content1 = MyConsole.ReadLine();
MyConsole.WriteLine(content1);
...
```

> 为了减少篇幅，后续很多演示内容就不贴完整代码了。

![获取用户输入运行结果截图](images/75db937f-e5bf-4e8b-9974-fd840e38bccf.png)

* 还是老样子，第一行先输出文本： `请输入要计算的第一个数字：` ；
* 第二行我输入了 `123` 并敲击 `Enter` 回车键。；
* 第三行打印变量 `content1` 中的内容，就是我输入的 `123` ；
* 最后计算 `100 + 200` ，输出 `300` 。

**整个过程依然是清晰的。**

只不过你输入的内容，并没有影响到变量 `num1` ，或者说并没有参与到计算中去，仅仅只是用 `content1` 这个变量记录了用户输入的值。

所以下面咱们就来把这个用户输入的值用起来了。


## 不同类型的变量运算

要想把我们输入的值用起来也不是什么难事，只需要将 `content1` 的值直接赋值给 `sum1` 就行了。

赋值操作之前咱们已经说过了，也就一句代码的事情。

``` Csharp
...
//int num1 = 100;
int num1 = content1;
...
```

原先赋值 `100` 的操作直接注释掉，改成存着输入值的变量 `content1` 就行了。

但是这里我们忽略了一个问题，`C#` 是类型强相关的语言。 `content1` 是 `string类型` ，  `num1` 是 `int类型` ，它们不能直接进行赋值。

会出现如下报错：

![string类型赋值给int类型报错截图](images/b0dcb336-a223-4032-a050-bd9531caaf14.png)

> 这里也是最让别人疑惑的地方，因为我输入的确实是数字 `123` 呀，为什么就不能赋值呢？
> 这是因为是否是数字你是知道，程序是没法进行思考。在这里你输入的内容是一个字符串，是 `string类型` 的，是 `"123"` ，而 `int类型` 需要的是 `123` 。

**这里就需要我们进行类型的转换。**

把 `string类型` 转换成 `int类型` ，即把 `"123"` 转换成 `123` 。

转换方法倒是不难， `C#` 中也给我提供了，直接调用 `int类型` 下面的 `Parse()` 方法即可。

最终代码就变成了：

``` Csharp
...
//int num1 = 100;
int num1 = int.Parse(content1);
...
```

现在你就可以开始测试这个程序了，会发现每次输入的值，先是存进了 `content1` ，然后经过数字转换存进了 `num1` ，最后随着 `num1` 和 `num2` 的运算，最终存入了 `sum` 。

![演示num1获得赋值变量计算截图](images/4148e2ac-108d-47fd-a01d-6adf1fec944b.png)

随着你输入值的不同，每次计算的结果也不一样，这是否还是挺有成就感的。

不过你要是敢于尝试，随便输入了一个不能转换成数字的内容，比如输入 `abc123` 再敲击 `Enter` 回车键，那就会立马得到一个错误。

![演示num1获得赋值变量计算截图](images/47b0f611-4f05-48e5-91f4-a6ce18b32d9f.png)

很显然 `abc123` 并不是一个有效的数字，所以这里转换报错了也是合情合理的。

**程序如果遇到报错，你不主动进行处理的话，程序就直接退出了。**

目前咱们对报错也无能为力，所以请你暂时先输入能够转换成数字的内容，进行测试。

### 改造num2

现在我们已经改造了 `num1` 为用户输入的值了。

下面就让我们来改造 `num2` 吧。

其实也是非常的简单，这里就直接贴代码了：

``` Csharp
...
MyConsole.WriteLine("请输入要计算的第一个数字：");
string content1 = MyConsole.ReadLine();
MyConsole.WriteLine(content1);

//int num1 = 100;
int num1 = int.Parse(content1);

MyConsole.WriteLine("请输入要计算的第二个数字：");
string content2 = MyConsole.ReadLine();

//int num2 = 200;
int num2 = int.Parse(content2);

int sum = 0;

sum = num1 + num2;
...
```

同样的，我们也是先进行了一个友好的提示： **请输入要计算的第二个数字：** 。

然后定义个一个新的变量 `content2` ，最终把 `content2` 转换成 **int类型** ，并且赋值给 **int类型** 的 `num2` 。

剩下的加法计算和输出就不做过多介绍了。

测试结果就类似于下方这样：

![演示num1和num2替换输入计算结果截图](images/cad31609-65ac-4669-883f-1b4c7c1aea1e.png)

根据提示依次输入两个数字内容，最终得到计算结果。
